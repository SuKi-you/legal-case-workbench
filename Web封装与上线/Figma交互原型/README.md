# 案卷工作台 · 交互组件

本稿使用同一宗虚构劳动争议。界面采用暖纸底、墨色文字、铜棕焦点和细分隔线。大标题用宋体，正文用清晰的无衬线字体。颜色用于选中、原文定位和待核状态，状态同时有文字标签。

| 色彩 | 色值 | 用途 |
| --- | --- | --- |
| 暖纸 | `#F6F4EF` | 案卷工作区背景 |
| 墨色 | `#232621` | 标题与正文 |
| 铜棕 | `#805638` | 主按钮、选中和证据定位 |
| 待核棕 | `#86501F` | 待核标签与需要对照的字段 |
| 纸灰线 | `#DEDBD0` | 材料、字段及版面分隔 |

## 三个操作

1. **证据镜片。** 点击左侧工资表里的 6,000，将它带到校对框。保存 v2 后再点「回看 v1 引用」，看到旧引用仍返回当时识别的 8,000。
2. **因子对照。** 先比较 6,000 元应发与 5,400 元实付，再切换到同一谈话的两种说法。对照项与原文一起变化，口径差异和相反陈述分别呈现。
3. **补料轨迹。** 补入 M05，观察时间线和前后差异。文件载明的日期进入台账，口头陈述保留，送达与效力仍列为待核。可回看补料前。

用浏览器打开 [交互预览.html](交互预览.html) 即可体验。预览的数据和操作只用于演示。

## 导入 Figma

1. 解压导入包，在 Figma **桌面版**打开一个可编辑的 Design 文件。
2. 在菜单选择 **Plugins → Development → Import plugin from manifest**，选择包内 `figma/manifest.json`。
3. 在 **Plugins → Development** 运行「案卷工作台」插件。生成的页面包含组件与原型画板。在 Prototype 面板选定起点，再点击 Present 预览。

导入使用 Figma 桌面端的开发插件机制。[Figma 官方导入说明](https://help.figma.com/hc/en-us/articles/360042786733-Create-a-classic-plugin-for-development)

浏览器已检查 1240、390、320 像素宽度，以及校对、旧引用、键盘切换、两份出处和补料回看。Figma 导入脚本通过本地模拟验证，生成 8 张画板、3 组组件变体和 24 条点击连线。实际桌面端导入尚待验证。
