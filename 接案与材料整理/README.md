# 接案与材料整理

使用 [VS Code 工作区](../法律Agent-优化版.code-workspace)打开优化版。按 F5 选择劳动法入口，输入案件序号，再输入 `/intake`。命令会用已安装的劳动法需求整理材料、保存专业复核并导出底稿。

也可在底座目录直接执行：

```powershell
npm.cmd run agent:labor -- --case '案件ID' --workflow intake
```

先用底座的案件命令创建案件、登记文字或照片、对照片执行 OCR，并按需要校对文字。每份材料默认使用唯一的当前文字版本。有多个分支时，用 `--select 材料ID=版本ID` 明确选择，其他唯一版本继续自动纳入。来源登记为书面记录时，可由录入人指定 `--source-kind 材料ID=document_record`。

接案成果包括材料索引、时间线、带固定版本出处的陈述、差异、缺项和专业待办。模型拒绝某条候选时，其余已核验需求继续保留。仍无法核验的需求和来源在 JSON、Markdown、Word 中列为待核。底稿的已保存状态与材料覆盖、专业复核状态分别显示。

终端输出 `WORKFLOW_RESULT`，包含会话 ID、整理运行 ID、底稿 ID、覆盖统计和三种文件路径。后续以底稿 ID 作为[节点审查基线](../关键节点审查与准备/README.md)。中断后可通过同一会话 `--session 会话ID --resume` 恢复。材料改变时，按当前材料发起新一轮流程。

本地工具操作见[底座运行说明](../底座/README.md)，验收方法见[验收说明](../评测与验收/Web前验收说明.md)。
