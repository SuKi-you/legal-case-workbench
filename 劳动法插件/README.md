# 劳动法插件 0.6.0 · 接案与节点审查

这是在保留 v0.4.0 原件之后形成的独立优化副本。沿用 `kernel / labor / adapter`，专业差异仍以知识包、参数和纯函数承载。底座负责材料、出处、运行与保存；专业复核器返回需要核对什么及下一步动作。

0.6.0 接入同一案件的答辩、新证据与庭前准备，通过 `contributeNodeReview` 提供通知、工资和合同等专业准备事项。参见[节点审查用法](../关键节点审查与准备/README.md)。

## 接入

保持与 `底座/` 同级，在底座目录运行：

```powershell
npm.cmd run agent -- --plugin ../劳动法插件/src/index.ts
```

CLI 的工厂接收 `dataDir`。运行时优先使用底座提供的案件绑定读取、受预算控制的模型服务与取消信号。独立测试仍可注入 `loadRun`、`model`；插件通过 `src/base.ts` 依赖公开的 `底座/src/plugin-api.ts`。

## 此次修正

- 每个要件分别保留 `informationState`（资料覆盖）和 `state`（专业状态）。正向条件遇到明确否定为 `opposed`，歧义和未完成范围保留待核。评价性要件已有可用材料时仍记为 `needs_review`，可用材料供参考意见使用，专业判断由人完成。
- 每个争点的规则按顺序检查，最后一条须为 `all: []` 的兜底规则，保证其余状态组合也有明确处理。
- 任意解除理由不再同时触发严重违纪、不能胜任抗辩。关键词只用于候选线索，劳动抗辩必须专业核对，不能自动阻断路径。任务目标中的词语不作为证据。
- 普通通知、劳动管理等不强制要求原文事件编号；时间、提出方和工资口径分开询问。同一专业信息需求合并追问，已有单位通知记录时不为完全无记录的另两种提出方重复提问。
- `reviewers` 接入底座 loop；专业检查与通用 coverage 并列保存。补读仅指向已声明需求和选定来源，材料读完后区分缺信息和需人工判断。
- 评价意见只能引用真实 `citation.quote`，不能引用模型归纳冒充原文。超过单次60条记录明确要求缩小范围，不静默截断；专业材料不明时只接受 `unclear/low`。意见不改写要件状态。
- 代通知金按上一个月工资计算，不套经济补偿三倍封顶。日期型补偿保留不足整月零头；二倍工资不足整月可显式提供实际工作日和经确认日工资，拒绝猜测小数月。
- 计算将参数核验与法律适用分开。`parametersVerified` 表示参数状态，`applicabilityVerified:false` 保留承办人对路径与口径的判断；非法日期返回 `total:null / not_computed`，不是0元。跨2008年前段仍属 `historical_draft`、整体 `verified:false`。
- 裁剪争点时，依赖被裁掉条件的抗辩整条不参与，不把 A 且 B 改成只有 A。核心信息缺失不能被其他规则绕过。

## 专业校验条件契约

`CheckSpec` 的 `when` 为状态或材料线索词条件数组；`claim` 为明确记录值条件；`gap` 为已计算缺口条件。三类条件可以单独使用，也可以组合使用，组合一律为 **AND**：`when` 内每一项、已提供的 `claim`、已提供的 `gap` 均须满足。

`when: []` 合法，前提是另有有效 `claim` 或 `gap`。例如其他专业插件可以只声明 `claim: { needId: 'domain.need.result', values: ['已交付'] }`，或只声明 `gap: { elementId: 'domain.delivery', kind: 'missing_document' }`；引用的需求、要件须在知识包内声明。`claim.values` 中的值为可接受值集合（其中一个匹配即可），不等于多个条件同时成立。

三类条件全空、空白线索词、空状态/值集合、非法状态或缺口类型、未声明的需求/要件引用均不合法。任一已提供条件无效，知识包校验会报错；即便绕过装配直接执行纯函数，该检查也不会触发。缺少匹配记录、缺口或执行上下文表示不满足，不会退化成无条件提醒。契约实现和执行复用 `src/kernel/check-conditions.ts`，通用正反测试见 `tests/check-conditions.test.ts`。

## 法律内容与边界

新增实施条例第二十条、劳动争议解释（二）第六、七条的官方地址与核验时间。原交付的其余摘要未在本轮全部逐条完成独立核验，统一明确标为 `unverified`，不假装已核验的现行法源。详见 [法律核验与计算边界](法律核验与计算边界.md)。

本插件服务于接案整理和专业复核准备。候选路径、抗辩、模型意见和金额测算均保留出处、缺项和适用假设。工伤待遇、年假、竞业限制及地方参数继续按既定范围处理。自我进化和 Web 沿用项目后续规划。
